# The Darkroom Atlas — 设计与路线

## Context

目标是在计算机里用物理方式模拟胶片的曝光、显影和成像，并能处理真实照片。仓库最终要容纳大量胶片、显影液和处理流程。仓库目前为空（未 `git init`）。

用户已定的事：

- **物理正确第一**，同时尽全力保证照片观感和不同组合之间的横向可比性。
- **顺序**：先搭底座，底座要能同时容纳黑白和彩色，只带少量胶片；底层、功能、运行顺序确定之后，再大量添加胶片和显影液数据。
- **做法**：要"真正物理、很专业"的做法，可以花较长时间。

我据此做的判断（不是用户原话，审阅时请留意）：

- 引擎用机理模型（下文 B），并把逐颗粒的显微镜模式（C）做进底座当参照。
- 观感只在出口端处理，不回头调物理参数迁就好看。
- 先做库 + 命令行 + 自动生成的对比图鉴，交互界面和 GPU 往后放。
- 版本号前缀用 `D`（Darkroom，忽略冠词 The）。

### 为什么值得做

现有开源项目里，spektrafilm 用厂商手册曲线做彩色负片，显影不是化学；Filmulator 模拟显影剂扩散，但不模拟具体胶片和颗粒。没有项目把"胶片 = 乳剂数据"和"显影液 = 化学配方"分开建模，让 N 种胶片 × M 种显影液的结果由模拟产生。

## 做法比较

| | 做法 | 取舍 |
|---|---|---|
| A | 曲线驱动：胶片是手册曲线，显影液是曲线修正 | 快，但显影液不是化学，新组合无法预测。只用作标定目标和验证基准 |
| **B** | **机理模型 + 手册标定**：颗粒群体、潜影动力学、显影速率方程、反应-扩散 | **选定为引擎**。显影液由配方得参数，胶片标定十几个参数，新组合是预测 |
| C | 微观蒙特卡洛：三维乳剂内逐颗粒 | 全幅算不动。作为小块区域的"显微镜模式"，用来校验 B 的统计 |

## 核心设计

### 三个对象，一条可拼接的链路

- **Material（感光材料）**：胶片和相纸用同一套结构。有序的层：保护层、各感光乳剂层、滤光层、防光晕层、片基。
- **Bath（药液）**：由化学配方描述，成分引用化学物种库。
- **Process（流程）**：有序步骤，每步含药液、稀释、时间、温度、搅动方式、药液量。

三个操作：

```
expose(material, light, time)  → EmulsionState   曝光
process(state, process)        → EmulsionState   按步骤冲洗
readout(state, device)         → 光谱透射/反射 或 图像
```

底片的光谱透射可以作为下一次 `expose` 的光源，所以暗房印相（放大机 + 相纸 + 相纸显影液）复用同一个引擎，不需要另写一套。

### 约定

- 波长网格 380–780 nm，步长 5 nm，可配置。
- 胶片平面长度单位 µm。由胶片画幅（mm）和像素数得到像素间距，所有物理尺度（扩散长度、光晕半径、颗粒大小）都用 µm 表达，因此结果与分辨率无关。
- 曝光量用每 µm² 每波段的光子数；密度用光谱光学密度。
- 所有随机过程带种子；横向比较时各组合用同一种子，差异只来自物理。
- 每次输出附带一份运行记录（配方、数据文件哈希、版本、种子），可完全复现。

### 物理链路

**0. 场景 → 光谱曝光**
主要输入是场景线性数据（RAW、线性 EXR/TIFF），也支持直接输入光谱图像。8 位 sRGB/JPEG 可以用，但已被裁切和压缩到约 6–7 档，负片的宽容度和高光表现基本体现不出来，运行时给出提示。RGB 还原为光谱用 Jakob & Hanika 2019 一类的方法，这是链路里最不物理的一步（同色异谱信息已丢失），文档里明说。
曝光由虚拟相机决定，与原数码照片的 EXIF 无关：默认按胶片标称感光度对场景做平均测光，换算成 ISO 标准的胶片面曝光量，可加曝光补偿。横向比较时默认每种胶片各按自己的标称感光度曝光同一场景。

**1. 乳剂内的光传输**
逐层计算光谱吸收；乳剂散射用每层点扩散函数表示。手册 MTF 是显影后测得的，已包含边缘效应（低频常超过 100%），所以点扩散函数不能直接对着手册 MTF 拟合，必须经过完整的正向模拟（含显影）来标定，否则边缘效应会被算两次；光晕按片基内反射计算（片基厚度、折射率、全反射临界角决定光晕环半径），彩色片上光晕先到达感红层，偏红是自然结果。

**2. 潜影形成**
每层的颗粒按尺寸分成若干档（对数正态分布；传统的多分散不规则碘溴化银颗粒与扁平 T 颗粒分别处理，两者的吸收截面和遮盖力不同）。每档颗粒吸收的光子数服从泊松分布。潜影用成核-生长模型（Gurney-Mott / Hamilton）：单个银原子不稳定会衰减，达到若干原子才稳定。实现为小型马尔可夫链，预先算成查找表。倒易律失效由这个模型自然产生，不另加经验公式。输出是每档颗粒在各潜影大小上的分布。

**3. 显影（核心）**
- 化学物种库：每种显影剂的摩尔质量、pKa、扩散系数、速率常数与活化能。覆盖米吐尔、对苯二酚、菲尼酮类（含 Dimezone S）、抗坏血酸盐、对氨基苯酚、邻苯二酚/邻苯三酚，以及彩色显影剂 CD-3、CD-4。摩尔质量、pKa、扩散系数取自文献；速率常数、吸附常数、再生速率在文献中没有成套的测量值，大部分将是标定值，如实标为 `fitted`。
- 显影速率取决于显影剂离子化形态的浓度、溴化物抑制（吸附型）、温度（Arrhenius）、颗粒大小和潜影大小。无潜影的颗粒以很低的速率显影，灰雾由此产生；潜影越小诱导期越长，增感显影（推冲）提速由此产生。
- pH 是随空间和时间变化的场，不是配方里的一个常数：显影每还原一个银离子释放酸，乳剂内 pH 会下降，幅度取决于药液的缓冲能力。缓冲组分随显影剂一起扩散。稀释或弱缓冲显影液的补偿效应依赖这一点。
- 超加和性（米吐尔-对苯二酚、菲尼酮-对苯二酚、菲尼酮类-抗坏血酸盐）通过再生反应的机理建模，而不是给配方整体乘一个系数；其中的速率常数是标定值。
- 亚硫酸盐：清除显影剂氧化产物，并作为卤化银溶剂（影响颗粒与感光度）。
- 空间：每个像素在深度方向分为乳剂层和药液边界层的若干单元，横向二维扩散，外接一个有限体积、充分混合的药液槽。搅动把边界层重置为槽内浓度。稀释显影的补偿效应、边缘效应、一次性药液的耗尽都由此产生。
- 数值：算子分裂，扩散隐式求解，反应用刚性积分器，自适应时间步。大图分块计算，块间重叠大于扩散作用范围。

**4. 成像**
- 黑白：已显影银量 × 遮盖力 → 密度（Nutting 公式按颗粒档求和）。染色显影液（Pyro 类）的染色密度由未被亚硫酸盐清除的氧化产物得到。
- 彩色：氧化的彩色显影剂与成色剂耦合生成染料；DIR 成色剂释放抑制剂并扩散，层间效应由此产生；带色成色剂随染料生成而消耗，橙色色罩是自然结果。染料光谱密度取自手册。
- 反转片：首显（黑白）→ 反转 → 彩显，正像由剩余卤化银得到。交叉冲洗、漂白旁路不需要专门代码，只是不同的步骤组合。

**5. 停显、定影、漂白、水洗**
简化的一阶模型，但作为真实步骤改变状态。缩短或跳过会有相应后果（如定影不足留下残余卤化银）。

**6. 颗粒**
- 统计模式（全幅）：每像素每档的已显影颗粒数按二项分布抽样，颗粒噪声的统计量是正确的。
- 显微镜模式（小块）：三维乳剂内显式放置每一颗颗粒，逐颗粒算曝光和显影，用布尔模型渲染（Newson 2017）。用来检验统计模式，也可直接出放大图。

**7. 出口**
- 密度计：Status M / Status A / 视觉漫射密度，用于验证。
- 标准扫描：固定的虚拟扫描仪和固定的反相规则，定义一次并写入文档。底座阶段的可比出口。
- 标准印相：固定参考相纸，曝光时间按"片基达到最大黑的最短时间"确定。这是真实暗房里的标准样片做法，物理上最干净的可比出口。相纸反射密度用 Williams-Clapper 模型。

### 数据

全部为纯数据文件，放在 `data/`：

```
data/chemistry/species.yaml        化学物种及动力学常数
data/developers/<name>.yaml        配方（g/L）、稀释、pH
data/films/<maker>/<name>.yaml     层结构、颗粒、光谱敏化、成色剂、片基
data/papers/...                    与胶片同一结构
data/processes/<name>.yaml         步骤序列
data/reference/<material>/*.csv    从厂商手册数字化的曲线
```

**每个参数都带来源标签**：`datasheet`（手册）、`literature`（文献）、`fitted`（标定得到）、`assumed`（假设），并尽量带不确定度。显影液配方另带可信度：`published`（公开配方，如 D-76、D-23、D-72、Pyrocat-HD）、`patent`（专利）、`msds-estimated`（由安全数据表推算，如 HC-110）。

所有曲线从厂商手册自行数字化，不拷贝其他项目的数据。不使用 Massive Dev Chart 等有版权的汇编数据。

用户目前没有冲洗条件，现阶段只用公开数据。参考曲线文件带 `origin` 字段（现在只有 `datasheet`），以后有实测数据时可以加 `measured` 而不改格式；实测数据的导入工具现在不做。

### 验证

每种胶片配一份自动生成的验证报告。虚拟感光仪曝光 21 级光楔，走完整流程后测量：

| 项目 | 对照 |
|---|---|
| 特性曲线（密度-对数曝光量） | 手册曲线 |
| ISO 感光度 | 标称值 |
| 反差指数随显影时间的变化 | 手册曲线，多种显影液 |
| RMS 颗粒度（48 µm 孔径，密度 1.0） | 手册数值 |
| MTF | 手册曲线 |
| 倒易律修正 | 手册表格 |
| 光谱敏感度 | 手册曲线 |

**预测能力的检验**，这是整个项目"物理是否成立"的核心判据。为避免循环论证，标定用的数据和检验用的数据严格分开：

- 胶片参数：每种胶片只用一种参考显影液（D-76）的手册曲线标定。
- 化学常数：对所有胶片通用，在一组"训练组合"上联合标定。
- 保留组合：从不参与任何标定，只用来检验。D1 的划分是：训练用 Tri-X×D-76、Tri-X×XTOL、Tri-X×HC-110、T-Max 100×D-76；保留 T-Max 100×XTOL 和 T-Max 100×HC-110。保留组合里，胶片参数来自 D-76，显影液常数来自另一种胶片，两者从未一起出现过。
- 同一组合内，稀释比例、温度、显影时间的变化也留出一部分只做检验。

**每个组合带验证状态**，在图鉴里显示：`validated`（有参考数据且达标）、`predicted`（纯预测，无参考数据可对照）、`failed`（有参考数据但不达标）。大量扩充后多数组合会是 `predicted`，这一点不掩饰。

另有单元级检查：银和显影剂的物料守恒、扩散求解器对解析解、极限情况（零曝光只有灰雾、无限时间趋于最大密度）、时间步与网格收敛、分块无接缝、改变像素数后曲线与颗粒度不变。

### 已知的不物理之处（如实记录）

- RGB → 光谱的还原。
- 乳剂配方是商业机密，胶片参数是标定值。
- 部分专有显影液配方是推算值。
- 显影动力学常数大部分是标定值而非实测值；模型的结构是物理的，常数的可信度靠保留组合的预测误差来衡量。

这些都在数据的来源标签和验证报告里体现，不隐藏。

## 技术选型（我的决定）

- Python 3.13，`uv` 管理环境（本机已有 uv 0.11、Python 3.13.5，M4 Pro / 48 GB）。
- NumPy / SciPy 为核心，代码按 Python Array API 写，以后可换 GPU 后端。
- 数据模型用 pydantic 校验；测试用 pytest，数值模块先写测试再写实现。
- 命令行入口 `atlas`：`atlas run`（处理图片）、`atlas validate`（验证报告）、`atlas sheet`（对比图鉴）。
- 性能目标：不追求实时。全幅图几分钟可接受；预览用较少像素、相同物理尺寸。

## 路线

大版本对应阶段；阶段内每完成一个模块推进一个中版本。每个阶段开始前插入章节标题，每次完成修改后更新 README 的版本记录与 version 徽章。

**D0 底座与约定**
`git init`；项目骨架；单位与光谱网格；数据模型与来源标签；`Material / Bath / Process / EmulsionState` 与三个操作的接口；分块机制；运行记录；命令行；测试框架；`docs/physics.md` 骨架；README（徽章行在无远程仓库时只放 version 一枚）。
完成标准：一张图能经"理想材料"走通 曝光 → 冲洗 → 出口 全流程并产出运行记录，测试全绿。

**D1 黑白物理链路**
按顺序：场景与光传输 → 潜影模型 → 化学物种库与显影反应-扩散 → 银密度与颗粒统计 → 虚拟感光仪、标定、验证报告 → 显微镜模式。
首批数据：Kodak Tri-X 400（传统颗粒）、Kodak T-Max 100（T 颗粒）；显影液 D-76（参考标定）、XTOL（抗坏血酸盐 + Dimezone S，配方来自专利）、HC-110（配方为推算值）。这三种在 Kodak 手册里应有曲线，下载手册后核实，缺的换成手册里有的显影液。另加 Rodinal 作为没有手册参考数据的例子，状态标为 `predicted`。
完成标准：训练组合各验证项达标；两个保留组合的预测与手册对照并给出误差；统计模式与显微镜模式的颗粒度一致。

**D2 彩色物理链路**
多层乳剂、成色、DIR 层间效应、色罩、漂白与定影；反转流程。
首批数据：Kodak Portra 400（C-41）、Kodak Ektachrome E100（E-6）。
完成标准：两种胶片的中性灰特性曲线、光谱染料密度、光谱敏感度、MTF 达标；交叉冲洗和漂白旁路仅靠改流程文件即可运行，状态标为 `predicted`。
彩色流程只有一种显影液，没有"换显影液"的保留检验，改用手册里的推冲数据和显影时间、温度变化做保留检验。彩色负片手册多给 Print Grain Index 而非 RMS 颗粒度，颗粒按手册实际提供的指标对照。DIR 和层间效应的参数若找不到分色曝光的公开数据，标为 `assumed`，不声称已验证。

**D3 暗房印相**
放大机光源与滤镜、相纸（可变反差相纸的多乳剂）、相纸显影液、反射密度、调色步骤；标准印相出口。

**底座评审点**：D3 结束后与用户一起确认底层、功能和运行顺序，再进入 D4。

**D4 图鉴扩充**
批量添加胶片、显影液、流程；手册曲线提取工具的批量化；对比图鉴页面。

**D5 性能与界面**
GPU 后端、交互界面。
